# AI-Generated vs. Real Image Detection via Latent Space Analysis

This repository contains the research, experiments, and implementation of our undergraduate thesis on **AI-generated vs. real image detection using latent space analysis**.

The project investigates how AI-generated and real images differ within learned latent representations and explores whether these differences can be leveraged for effective and reliable detection. We experiment with deep learning models, latent feature representations, and various analysis techniques to understand the underlying patterns and limitations of AI-generated image detection.

This work aims to contribute toward a better understanding of how generated images can be distinguished from real images through their learned representations.
